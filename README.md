# Kai 復縁タロット：自動投稿リポジトリ

3択画像は親投稿用の1枚だけを、制作チャットで毎週新規制作します。A・B・Cの子投稿は文字のみです。

- 3択の親画像：1080×608
- 親画像は新規制作した3枚を同じ大きさで配置
- A・B・Cは各カードの外側・真上へ表示（カード絵柄には重ねない）
- 画像全体を囲む外周枠は入れない
- 親画像にタイトル、案内文、結果文などは入れない
- A・B・Cの結果は返信本文へ記載し、子投稿用画像は制作・添付しない
- 過去のカードPNG、カードID一覧、背景差し替え、切り抜き、再配置、Python合成は禁止
- 子投稿に`image_path`がある既存データは画像付き、ない新規データは文字のみで投稿する
- GitHub側で画像を生成・補完しない。親画像が欠けている場合は投稿を停止する

## 更新対象

- `app/threads_api.py`：画像コンテナの完了待ちとAPIエラー本文の記録
- `data/content_queue.json`：予約投稿データ
- `generated/`：投稿に使用する完成画像
- `docs/KAI_TAROT_IMAGE_RULES.md`：画像制作ルールの正本

## アップロード

完成画像と投稿データだけを差分として投入します。カード素材集や画像生成コードはアップロードしません。
