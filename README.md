# Kai 復縁タロット：投稿画像・予約投稿更新

この更新では、3択投稿を次の仕様へ統一します。

- 3択の親画像：1080×608
- A・B・Cの結果画像：1080×1350
- 親画像は元カードの縦横比を維持して3枚を同じ縮尺で配置
- A・B・Cは各カードの外側・真上へ表示（カード絵柄には重ねない）
- 画像全体を囲む外周枠は入れない
- 親画像にタイトル、案内文、結果文などは入れない
- 結果画像は対応するカードだけを表示し、説明文は返信本文へ記載

## 更新対象

- `app/image_maker.py`：画像生成仕様
- `app/threads_api.py`：画像コンテナの完了待ちとAPIエラー本文の記録
- `data/content_queue.json`：2026年8月4日までの投稿データ
- `generated/`：投稿に使用する完成画像
- `tarot_cards/compose_post.py`：手動生成用コマンド
- `tarot_cards/README.md`：画像仕様と実行方法
- `tests/test_image_spec.py`：画像寸法と内容の検査

`tarot_cards`内の22枚のカードPNGと`cards.json`は素材なので、今回の更新対象ではありません。

`generated/`には2026年7月28日夜から8月4日夜までの親画像8枚と
結果画像24枚、合計32枚を収録しています。

## アップロード

ZIPを解凍し、中のファイルとフォルダをGitHubリポジトリ直下へアップロードして同名ファイルを上書きします。

上書き後、8月2日夜枠を`dispatch`でテストし、親投稿と同じ親へのA・B・C返信3件がすべて公開されることを確認してください。
