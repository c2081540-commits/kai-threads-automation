今回アップロードするもの

GitHubリポジトリ kai-threads-automation の Code 画面で
「Add file」→「Upload files」を開き、このZIPを展開して出てきた
フォルダとファイルをまとめてドラッグしてください。

必ず「kai_threads_weekly_system_v1」という外側のフォルダではなく、
その中身をアップロードします。

上書きされるファイル:
.github/workflows/threads-daily.yml
app/cli.py
app/image_maker.py
app/queue.py
tests/test_system.py

新しく追加されるファイル:
app/weekly.py
data/weekly_package.json
GPT_WEEKLY_OPERATOR.md
WEEKLY_OPERATION.md

アップロード後:
1. Commit changes を押す
2. Actions → Threads scheduled dispatch
3. Run workflow
4. 実行内容を validate_week にして実行
5. 緑色のSuccessになったら、次は prepare_week で実行

validate_week と prepare_week はThreadsへ投稿しません。
Threads API要求も0回です。
