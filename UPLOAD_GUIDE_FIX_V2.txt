アップロード手順

1. このZIPをMac上で展開します。
2. GitHubの kai-threads-automation を開きます。
3. Code → Add file → Upload files を開きます。
4. 展開してできたフォルダの中身を、まとめてアップロード欄へ入れます。
   kai_threads_image_fix_v2 という外側のフォルダ自体は入れません。
5. Commit changes を押します。
6. Actions → Threads scheduled dispatch → Run workflow を開きます。
7. 実行内容で prepare_week を選び、Run workflow を押します。
8. 完了後、Code → generated で次を確認します。

   post-00009-result-A.png

AUTO_PUBLISH はまだ true にしないでください。
